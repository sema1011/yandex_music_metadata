# yandex_music_metadata
Fetches additional metadata (lyrics, genre, explicit flag) from Yandex Music.

UUID замените на свой — можно сгенерировать командой picard-plugins --manifest.

Picard: Options → Plugins → Install plugin… → выбрать папку yandex_music_metadata или git репозиторий

После установки:

    В Options → Plugins → Yandex Music — включить и выбрать, что загружать.
    В Options → Cover Art — добавить «Yandex Music» в список провайдеров обложек.
