# Yandex Music Metadata Plugin for Picard

Плагин для MusicBrainz Picard, который автоматически дополняет метаданные музыкальных файлов данными из Яндекс Музыки: жанр, метка «18+», тексты песен и обложки альбомов.

**Репозиторий**: [yandex_music_metadata](https://github.com/sema1011/yandex_music_metadata)

## Возможности

*   **Поиск по ISRC** — приоритетный режим поиска для максимальной точности совпадения треков.
*   **Автоматическое определение жанра** — извлечение жанра трека или альбома из каталога Яндекс Музыки.
*   **Метка Explicit** — простановка флага `yandex_explicit = true` для треков с возрастным ограничением.
*   **Загрузка текстов песен** — поддержка получения полного текста (требуется OAuth-токен).
*   **Обложки альбомов** — загрузка изображений в высоком разрешении.
*   **Защита от блокировок** — встроенный rate limiter для предотвращения ошибок HTTP 429.

## Требования

*   **MusicBrainz Picard** версии 3.0 или выше.
*   **Python** 3.9 или выше (используется внутри Picard).
*   **Операционная система**: Windows, macOS, Linux.

## Установка

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/sema1011/yandex_music_metadata.git
    ```
2.  Скопируйте папку `yandex_music` в директорию плагинов Picard:
    *   **Windows**: `%APPDATA%\MusicBrainz Picard\plugins`
    *   **macOS**: `~/Library/Application Support/MusicBrainz Picard/plugins`
    *   **Linux**: `~/.config/MusicBrainz Picard/plugins`
3.  Перезапустите Picard. Плагин появится в списке (`Инструменты → Плагины`).

## Настройка

В настройках плагина (`Инструменты → Параметры → Плагины → Yandex Music`):

*   **Получать метаданные**: главный переключатель.
*   **Токен Яндекс Музыки**: вставьте OAuth-токен для загрузки текстов. (в работе)
*   **Искать по ISRC**: рекомендуется включить.
*   **Что загружать**: выберите нужные поля (Жанр, Explicit, Тексты, Обложки).

## Поля метаданных

| Поле | Описание |
| :--- | :--- |
| `yandex_genre` | Жанр трека или альбома. |
| `yandex_explicit` | `true`, если трек помечен как «18+». |
| `lyrics` | Полный текст песни. |
| `front_image` | Обложка альбома. |
